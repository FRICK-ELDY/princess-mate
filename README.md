# PrincessMate

**PrincessMate** は、横スクロール型のユニット配置バトルを軸にしたゲームプロジェクトです。スマートフォン向けタイトル「にゃんこ大戦争」のような、陣地からユニットを送り出し、敵本拠を目指すプレイ感を目指しています。

## コンセプト

- **陣取り・押し合いバトル**: 自陣からコストに応じてユニットを出撃させ、敵側のゴール（本拠）を崩す流れを想定しています。
- **チェスをモチーフにした役割名**: 駒の名前でユニットの役割を表現します。ただし **キングに相当するユニットは「プリンセス（Princess）」** とし、物語上・ゲーム上の中心キャラクターとします。

### 想定している駒モチーフの例

| モチーフ | ゲーム内の位置づけ（案） |
|----------|---------------------------|
| Princess | 自陣の要。これを守りつつ、敵本拠を叩く戦略の核。 |
| Queen / Rook / Bishop / Knight / Pawn など | それぞれ異なるコスト・射程・移動・攻撃特性を持つユニットとして展開する想定。 |

※ 具体的なステータスや駒との対応は、設計が固まり次第 README や別ドキュメントに追記します。

## 技術スタック（予定）

| 領域 | 技術 |
|------|------|
| ゲームエンジン | [Godot Engine](https://godotengine.org/) |
| ロジック・拡張 | [Rust](https://www.rust-lang.org/)（Godot との連携は GDExtension 等を想定） |
| キャラクター表現 | [Spine](http://esotericsoftware.com/)（2D スケルタルアニメーション） |

Godot 上で Spine 用ランタイムを組み合わせ、重い処理やルール部分を Rust で切り出す構成を想定しています。
